# Data Availability

The dataset `VHeduc_Data.dta` required to run this project is not hosted in this repository due to copyright and licensing guidelines.

# Download Instructions:
1. Visit the official AEA replication package page: [AEA Article & Data Repository](https://www.aeaweb.org/articles?id=10.1257/app.20150447).
2. Navigate to the **Replication Packages** section.
3. Download the data package and extract `VHeduc_Data.dta`.
